Generado con la herramienta integrada `image_gen`, usando `public/assets/personajes/temayin-decidido.webp` como referencia del personaje. El original se conserva en `temayin-master.png`; los archivos PNG e ICO se exportaron a los tamaños de uso sin cambios al diseño.

## Prompt final

Use case: logo-brand. Asset type: a single square favicon for Temayin, a friendly jaguar adventure game website. Use the attached reference image only as character identity reference. Create a NEW simplified favicon design showing only the jaguar's head, frontal and centered: round ears, golden yellow fur, a few large dark jaguar spots, confident friendly amber eyes, cream muzzle and a dark brown nose. Flat polished cartoon icon, thick clean dark outlines, bold simple shapes that remain readable at 16 and 32 pixels. Palette matches website: golden yellow #f7b94b, cream #f4e1b5, deep jungle teal #081b22. Square opaque deep jungle teal background with the head filling about 86 percent of the canvas, ears and chin fully inside. No body, clothing, lettering, text, watermark, border, collage, mockup or presentation sheet. One single finished favicon image.
